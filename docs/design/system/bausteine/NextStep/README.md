# NextStep

Karte mit genau einem nächsten Schritt: der Kern jeder Übersicht und jeder Bewerbung.

**Der Verwender liefert:** Kontext in `next-step__eyebrow` („Nächster Schritt · Stelle, Firma“), den Schritt als Handlung in `next-step__title`, einen Satz warum, genau einen `btn--primary`, optional einen leisen Ausweg und in `next-step__after` den Schritt danach oder eine Frist.

**Wo:** oben auf Übersicht und Bewerbung. Auf der Übersicht bis zu drei Karten untereinander (dringendste zuerst), danach die Liste.

**Beispiele für Titel:** „Lebenslauf-Variante wählen“, „Anschreiben lesen und freigeben“, „Formular bei Muster AG ausfüllen“, „Versand festhalten“, „November im Job-Room eintragen“.

**Nicht:** mehrere Hauptknöpfe; Titel als Zustand („Anschreiben fehlt“) statt Handlung; farbiger Rand links.
